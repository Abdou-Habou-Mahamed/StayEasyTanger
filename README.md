# 🌍 StayEasyTanger

## 📌 Description
StayEasyTanger is a web platform that allows international students in Morocco to complete an online pre-registration process for residence permit applications in a simple and digital way.

The system helps students submit their information online before the official administrative procedure.

## ⚙️ Technologies used
- PHP  
- MySQL  
- HTML, CSS  
- XAMPP (local server)

## 🎯 Objective
To simplify and digitalize the pre-registration process for foreign students applying for residence permits in Morocco.

## 💻 Features
- Online pre-registration form  
- Student data submission  
- Data storage in MySQL database  
- Simple and user-friendly interface  

## 🧠 Project type
Academic project (Web development)
